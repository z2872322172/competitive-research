# 排障手册

按现象索引常见问题。日志位置：后端 uvicorn 控制台（或 `backend/*.log`）、worker Celery 控制台、容器 `docker compose logs <service>`。

## 启动类

**后端启动报 `ModuleNotFoundError`**
→ 确认在 backend 目录、激活了 `.venv`；依赖版本以 `requirements.txt` 为准。

**前端页面打开但所有请求 404**
→ 后端未启动或端口不是 8000；检查 `http://localhost:8000/v1/health`。自定义后端地址通过 `VITE_API_BASE_URL` 配置。

**Docker compose 启动卡在 backend "waiting"**
→ backend 依赖 MySQL/Redis 健康检查，首次启动 MySQL 初始化约需 30-60 秒；`docker compose logs mysql` 观察进度。

**Docker compose 前端请求打不到后端**
→ 前端镜像构建时固化了 `VITE_API_BASE_URL`（默认 http://localhost:8000/v1）。后端地址变了需 `docker compose build frontend` 重建。

## 研究流程类

**任务一直 queued 不动**
→ inline 模式不会排队；若 `TASK_MODE=celery` 则确认 worker 存活：`GET /v1/worker/health`、`docker compose logs worker`。

**搜索阶段提示"未配置 Tavily API Key"**
→ 属预期降级：走 demo 数据；或在任务 `source_preferences` 提供手动 URL 走真实抓取链路。

**来源数量为 0**
→ 常见原因：① 无 Key 且未提供手动 URL；② 页面被 robots.txt 拒绝（`FETCH_RESPECT_ROBOTS=true` 默认开启）；③ 正文低于 400 字符被过滤（`MIN_SOURCE_TEXT_CHARS`）；④ 抓取重试耗尽（网络/超时，`FETCH_MAX_RETRIES` 默认 2）。

**Claim 阶段报 `schema_validation_failed`**
→ LLM 返回不符合 Schema 且修复管道无法挽救。该错误会传播（不静默 fallback），任务标记 failed 但可 resume 重试；偶发重试即可，持续出现检查 LLM 模型配置。

**任务 waiting_review 卡住**
→ 有低置信/冲突 Claim 等待人工审核，属预期。前端审核页逐条决策，或批量接受低风险项；审核后可触发报告重生成。

**报告生成失败（report.generate_failed 事件）**
→ 自动重试 3 次（warning→error）。持续失败查看事件 payload 的 error 字段；resume 可从 checkpoint 继续。

## 数据类

**任务数据"串"到别的空间**
→ 数据按 `X-Workspace-Id` 隔离。当前无鉴权（P7-42 暂缓），前端工作区 ID 来自 `VITE_WORKSPACE_ID` 环境变量，确认前后端一致。

**快照 / 导出文件找不到**
→ 本地模式在 `backend/storage/`（snapshots / reports）；MinIO 模式在 `verda-artifacts` 桶，对象键见导出响应头 `X-Artifact-Object-Key`；MinIO 故障时自动降级写本地卷（backend-storage）。

**想清空本地数据重来**
→ `DELETE /v1/dev/demo-data`（仅 demo 数据）；或本地开发清理脚本（dry-run 先看清单）：

```powershell
.\backend\.venv\Scripts\python.exe backend\scripts\cleanup_dev_artifacts.py          # dry-run
.\backend\.venv\Scripts\python.exe backend\scripts\cleanup_dev_artifacts.py --apply  # 执行
```

## 测试类

**pytest 报临时目录权限错误（Windows）**
→ 从项目根目录或 backend/ 目录运行，pytest.ini 已固定 basetemp；不要用第三方临时目录。

**前端测试某个文件失败**
→ `cd frontend; node --test src/<模块>.test.mjs` 单独复现；全量：`Get-ChildItem src -Filter *.test.mjs | ForEach-Object { node --test $_.FullName }`。

## 健康检查入口汇总

```powershell
Invoke-RestMethod http://localhost:8000/v1/health          # 后端
Invoke-RestMethod http://localhost:8000/v1/worker/health   # worker / 任务模式
Invoke-RestMethod http://localhost:8000/v1/metrics         # 指标
```
