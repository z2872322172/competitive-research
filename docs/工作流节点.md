# 工作流节点文档

研究主链路基于 LangGraph 实现，定义见 `backend/app/workflows/research_graph.py`。每个节点执行时写入 `node.started` / `node.succeeded` / `node.failed` / `node.skipped` / `node.retrying` 事件（含 input_summary / output_summary / duration_ms），是前端研究时间线与恢复机制的数据基础。

## 节点流水线

```
START
  → initialize_run      初始化运行
  → plan_research       研究规划
  → build_search_plan   构建检索计划
  → discover_sources    发现来源
  → fetch_sources       网页抓取
  → parse_sources       正文解析
  → extract_evidence    证据抽取
  → extract_claims      结论抽取
  → verify_claims       引用质检
  → generate_report     报告生成
  → review_gate         人工审核闸门
END
```

## 节点说明

| 节点 | 职责 | 失败影响 |
|---|---|---|
| initialize_run | 准备运行上下文、加载任务 scope | 不可恢复，任务失败 |
| plan_research | 理解需求，拆解竞品 / 维度 / 检索策略 | 可恢复，checkpoint 重入 |
| build_search_plan | 为每个竞品 × 维度生成检索关键词 | 可恢复 |
| discover_sources | Tavily 搜索或手动 URL（source_preferences / prompt 提取）发现候选来源；无 Key 时走 demo fallback | 可恢复 |
| fetch_sources | 真实抓取网页：robots 检查、域名限速、重试（默认 2 次）、大小/类型限制、HTML 快照存储 | 单源失败跳过并计数，全失败可恢复 |
| parse_sources | Trafilatura 正文解析（fallback stdlib 解析器），低质量正文过滤（< 400 字符） | 单源失败跳过 |
| extract_evidence | 从正文抽取可引用证据片段（quote + 定位信息 + 质量分） | 可恢复 |
| extract_claims | LLM 结构化抽取 Claim（JSON Schema 约束 + 修复管道）；无 LLM Key 或运行时失败回退规则抽取；schema 校验失败不静默 fallback（报错传播）；未知 evidence_id 的 Claim 被过滤 | schema 失败可恢复重试 |
| verify_claims | 引用完整性、置信度、冲突风险检查；低置信 / 冲突 Claim 标记待人工审核 | 可恢复 |
| generate_report | 结构化 Markdown 报告（执行摘要 / 关键结论 / 审核风险 / 引用覆盖率），失败重试最多 3 次（事件 severity warning→error 递进） | 重试耗尽任务失败 |
| review_gate | 有风险 Claim 时暂停等待人工审核（任务 waiting_review）；无风险直接放行 completed；审核决策后可触发报告重生成 | — |

## Checkpoint 与恢复机制

- 每个 run 的状态经 LangGraph checkpoint 持久化（WorkflowCheckpoint 模型）。
- 节点失败时事件 payload 携带 `retryable` 标志，决定前端呈现"恢复"还是"重试"入口。
- `POST /research-tasks/{id}/resume` 从最后成功的 checkpoint 继续，跳过已完成节点。
- Celery worker 重启后自动从 checkpoint 恢复进行中的任务。

## 关键设计约束

1. **证据链不可退化**：Claim 入库强制绑定 Evidence（无证据 Claim 被过滤），LLM 幻觉 evidence_id 无法通过。
2. **离线可运行**：无 Tavily Key → demo 数据 + 手动 URL；无 LLM Key → 规则抽取；两者都不影响主链路完整性。
3. **失败可见**：所有失败路径写入事件流（前端时间线 / 活动流可见），报告生成失败有专门事件与重试语义。

## 事件类型速查（前端时间线消费）

| 类别 | 事件类型 |
|---|---|
| 节点生命周期 | `node.started` / `node.succeeded` / `node.failed` / `node.skipped` / `node.retrying` |
| 业务过程 | `planning.started` / `search.started` / `source.found` / `evidence.created` / `claim.created` |
| 审核 | `review.required` / `review.decision_created` |
| 报告 | `report.created` / `report.generate_failed` |
| 运行 | `run.failed` / `run.canceled` / `run.resume_requested` / `task.completed` |
